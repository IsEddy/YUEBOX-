# 主流程图与异常分支

> **阶段**：P2 · 信息架构　**版本**：P2.0.0　**日期**：2026-11-01
> **要求**：02 文档 §P2 动作 ④「画主流程图（含 3 条分支）」
> **用途**：定义四屏之间的跳转关系与**全部异常出口**，确保没有死路。

---

## 1. 主流程（Happy Path）

```
┌─────────────┐
│  S1 启动页   │  动词：推开
│  开盒仪式    │  1800ms 后自动进入
└──────┬──────┘
       │ 自动（--d-page 360ms）
       ▼
┌─────────────┐
│  S2 分类页   │  动词：分格
│  5 格栅格    │  ① 馆藏精选横滑  ② 格/轴切换  ③ 搜索
└──────┬──────┘
       │ 点击任一文物卡
       ▼
┌─────────────┐
│  S3 详情页   │  动词：接近
│  图版＋题跋  │  ① 3 热点  ② 一眼看懂  ③ 工艺分解
└──────┬──────┘
       │ 点击底部 CTA「唤出这件宝」
       ▼
┌─────────────┐
│  S4 AR 页    │  动词：唤物
│  取景识别    │  五态闭环
└─────────────┘
```

**四屏对应四动词**：推开 → 分格 → 接近 → 唤物。**主流程是一条直线，没有回头箭头**——返回由各屏的 IC-07 承担。

## 2. 三条分支

### 分支 ①：搜索分支（S2 内部闭环）

```
S2 分类页
   │ 点击搜索条 / IC-06
   ▼
[搜索输入态]  ← 页内浮层，不新增屏
   │
   ├── 有关键词 → [有结果列表] ──点击──▶ S3 详情页
   │
   └── 无匹配 → [空结果态] 「这一格还是空的」
                   │
                   └── 3 枚推荐缩略 ──点击──▶ S3 详情页
                   │
                   └── 点击取消 ──▶ 回到 S2 默认视图
```

**出口检查**：✅ 有结果可进详情；✅ 空结果有推荐兜底；✅ 可取消返回。

### 分支 ②：收藏分支（半屏抽屉，不占第五屏）

```
任意屏
   │ 点击 IC-05 收藏
   ▼
[藏印抽屉]  半屏，从底部升起（--d-base 240ms）
   │
   ├── 印章生成 ──▶ 印章 0.8→1＋描金一圈 ──▶ 收藏成功 Toast
   │
   ├── 分享卡片 ──▶ 生成卡片 ──▶ 系统分享
   │
   └── 下滑 / 点击遮罩 ──▶ 关闭抽屉，**返回原屏原位置**
```

**关键约束**：抽屉**不改变当前屏的状态**，关闭后回到原位置（02 §P8 走查 T5 验证项）。

### 分支 ③：AR 降级分支（无实物／无权限）

```
S4 AR 页
   │
   ├── 有相机权限 ──▶ 取景框对准 ──▶ 扫描中 ──┬── 成功 ──▶ 结果卡
   │                                          └── 失败 ──▶ 斜纹提示 ──▶ 重试
   │
   ├── 无相机权限 ──▶ [C.1.4 权限降级] 遮罩 75%
   │                     │
   │                     └──「没有相机也能玩：进入演示模式」──▶ 手动触发识别
   │
   └── 无实物（在家） ──▶ [C.2.1 示例缩略] 点 3 枚之一 ──▶ 直接进入成功态
```

**出口检查**：✅ 有权限走正常流程；✅ 无权限有演示模式；✅ 无实物有示例；**没有死路**。

## 3. 全部异常状态与出口

| # | 状态 | 出现位置 | 用户能看到什么 | 出口 |
|---|---|---|---|---|
| 1 | 启动加载慢 | S1 | 进度停 60%＋「正在开盒…」 | 等待自动完成 |
| 2 | 启动失败 | S1 | 「盒子卡住了，轻触重试」＋朱漆描边按钮 | 点击重试 |
| 3 | 搜索无结果 | S2 | 「这一格还是空的」＋3 枚推荐 | 点推荐 / 取消 |
| 4 | 图片加载中 | S3 | 绢白底＋24px 描金呼吸圆环 | 自动完成 |
| 5 | 图片加载失败 | S3 | 同上＋「重新加载」 | 点击重试 |
| 6 | AR 扫描中 | S4 | 「正在唤醒它…」＋环形进度 | 自动完成 |
| 7 | AR 识别失败 | S4 | 「这件宝贝还在盒子里睡觉，换一件试试？」 | 重试 / 换示例 |
| 8 | 无相机权限 | S4 | 「没有相机也能玩：进入演示模式」 | 进演示模式 |
| 9 | 收藏成功 | 抽屉 | Toast「已收进你的印盒」 | 自动消失 |
| 10 | 分享取消 | 抽屉 | 无提示，静默返回 | 回到抽屉 |

> **状态覆盖核对**：空 / 错 / 加载 / 权限 **四类齐全**，AR 页**五态齐全**（待扫描/扫描中/成功/失败/无权限）。满足 02 §4 终检第 9 项。

## 4. 返回路径（每一屏都要能回去）

| 当前屏 | 返回方式 | 回到 |
|---|---|---|
| S2 分类 | 无返回（Tab Bar 切换） | — |
| S3 详情 | 左上 IC-07 | S2（保留滚动位置） |
| S4 AR | 左上 IC-07 | S3 |
| 藏印抽屉 | 下滑 / 点遮罩 / IC-10 | 原屏原位置 |
| 搜索浮层 | 取消 / IC-10 | S2 默认视图 |
| 放大层 | 双击 / 双指缩小 / IC-10 | S3 原图 |

**返回必须保留滚动位置**——这是走查 T5 的检查项。

## 5. Tab Bar 与分支的关系

Tab Bar 4 项，对应 4 个去处，但**只有 3 个是屏**：

| Tab | 指向 | 是否占屏位 |
|---|---|---|
| 宝盒 | S2 分类页（默认视图） | 屏 2 |
| 分格 | S2 分类页（格视图） | 屏 2（同屏不同态） |
| 唤物 | S4 AR 页 | 屏 4 |
| 藏印 | **半屏抽屉 B.4** | **不占屏位**（D-04） |

> **守住「四屏」的关键**：第 4 个 Tab 打开的是抽屉，不是第五屏。这一条写进设计说明。
