# 目录说明 · Directory Guide

> 每个目录**只放该阶段的产物**，不跨阶段堆放。空目录由 `.gitkeep` 占位。

| `02_IA/` | 导图源文件（`.xmind`）、节点映射表、流程图 | 视觉稿 | P2 |
| `03_规范/` | 色板、字阶、栅格、材质配方、图标规范页 | 整屏设计 | P3 |
| `04_四屏/` | S1–S4 工作文件、状态页、导出切图 | 图标源文件 | P4 |
| `05_图标/` | IC01–IC11 标准稿＋反白稿（SVG/PNG） | 四屏文件 | P5（P3 定调 5 枚） |
| `06_动效/` | 分镜表、关键帧表、原型、Harness 录屏、成片 | 静态设计稿 | P6 |

| `Source Han Serif/` `Source Han Sans/` `lxgw-wenkai/` `Inter/` | 四套 OFL 字体 | — | 只读，**不入 Git** |

## 文件命名约定

| 类型 | 规则 | 示例 |
|---|---|---|
| 内部工作文件 | `S<屏>_<用途>_v<两位数字>` | `S2_category_v03.jsd` |
| 图标 | `icon_IC<编号>_<中文名>_<标准/反白>` | `icon_IC01_宝盒_反白.svg` |
| 素材 | `src_<文物编号>_<用途>_<序号>` | `src_C1_molong_01.jpg` |
| 交付物 | `YUEBOX_博物馆数字交互小程序_<类型>` | `..._界面.pdf` |
| 过程截图 | `P<阶段>_<对象>_<步骤>` | `P4_S2_step3_排内容.png` |

> **交付物不带版本号**——版本由 Git 标签承载（见 `版本控制.md`）。
