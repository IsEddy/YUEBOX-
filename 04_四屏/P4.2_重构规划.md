# P4.2 重构规划

> **版本**：P4.2.0　**日期**：2026-11-02
> **触发**：用户反馈 8 类问题，经核查确认全部成立，且多数为架构缺陷而非样式问题

---

## 0. 用户反馈的 8 类问题 → 根因判定

| # | 用户反馈 | 根因 | 性质 |
|---|---|---|---|
| 1 | 点任何文物都是墨龙图 | `detail.html` 把「墨龙图」硬编码，无数据层，无 `?id=` 参数 | **架构缺陷** |
| 2 | 切换页面极其生硬，完全没有动画 | 只有 `splash` 有开盒动画；屏间跳转是浏览器默认跳转 | **缺失功能** |
| 3 | 空状态文字压在卡片上（图 2） | `.s2-empty` 用 `inset` 覆盖但 `z-index` 与滚动区冲突，且未隐藏原列表 | **结构缺陷** |
| 4 | 轴视图内容被截断、错位（图 3） | `.s2-axis` 高度边界与 TabBar 冲突，行高不够 | **布局缺陷** |
| 5 | 搜索框、分段控件样式单薄（图 1） | 只有 1px 描边，无底色层次；选中态与未选中态对比不足 | **视觉缺陷** |
| 6 | 详情页热点圆环压在文字上 | 热点绝对定位坐标未按实际图版尺寸校准 | **布局缺陷** |
| 7 | CTA 按钮与内容粘连 | `.s3-pad` 高度不足，内容贴到 CTA | **间距缺陷** |
| 8 | 整体不够「对齐化」 | 各屏间距未统一到 8pt 栅格；左边缘虽都是 24 但纵向节奏混乱 | **系统缺陷** |

**核心结论**：不是修修补补能解决的。**必须重做数据层 + 转场系统 + 重排间距节奏**。

## 2. 转场系统（解决「切换生硬」）

### 2.1 三级转场策略

| 场景 | 做法 | 时长/曲线 |
|---|---|---|
| **卡片 → 详情** | 共享元素转场：卡片图片飞至详情页图版位 | 420ms `cubic-bezier(.22,.61,.36,1)` |
| **屏间 Tab 切换** | 交叉淡入 + 轻微上移 | 240ms `cubic-bezier(.22,.61,.36,1)` |
| **返回** | 反向共享元素 | 360ms |
| **抽屉/浮层** | 上滑 + 遮罩淡入 | 240ms |
| **状态切换** | 淡入 + 8px 上移 | 180ms |

### 2.2 实现方案

**优先 View Transitions API**（Chrome 111+），降级用 FLIP：

```js
// 卡片点击
if (document.startViewTransition) {
  document.startViewTransition(() => { location.href = `detail.html?id=${id}`; });
} else {
  flipTo(id); // 手动 FLIP：记录卡片图位置 → 存 sessionStorage → 详情页读回做动画
}
```

**卡片与详情页图版共享 `view-transition-name`**：
```css
.gcard[data-relic="molong"] .pic img { view-transition-name: relic-image; }
.s3-figure .plate img { view-transition-name: relic-image; }
```

### 2.3 降级 FLIP 方案（必须实现，因为本地 file:// 可能不支持 VT）

1. 点击卡片：记录图片的 `getBoundingClientRect()` 存入 `sessionStorage`
2. 跳转详情页
3. 详情页加载：图片先按记录位置定位 → 动画到目标位置（420ms）

### 2.4 进入动画

每屏首次进入，内容按 8pt 节奏 stagger 上浮：
- 序号 0ms / 标题 40ms / 搜索条 80ms / 分段 120ms / 精选 160ms / 栅格 200ms
- 单元素 240ms `cubic-bezier(.16,1,.3,1)`

## 3. 间距节奏系统（解决「不对齐」）

### 3.1 建立 8pt 纵向节奏表

| 层级 | 间距 | 用途 |
|---|---|---|
| `--sp-1` | 4px | 图标与文字间隙 |
| `--sp-2` | 8px | 紧密关联 |
| `--sp-3` | 12px | 组内 |
| `--sp-4` | 16px | 组间 |
| `--sp-5` | 24px | 区块间 |
| `--sp-6` | 32px | 大区块 |
| `--sp-7` | 48px | 屏级分隔 |

### 3.2 各屏纵向节奏统一

**分类页**（y 坐标，全部落在 8 的倍数）：
```
44  状态栏
64  序号 02        ← 24 + 20
88  标题「分格」    ← 24 字高 36
136 搜索条(44高)
196 分段控件(44高)
256 馆藏精选(标签+卡 68+16)
356 主栅格开始
722 TabBar 上沿
```

**详情页**：
```
0   图版（按实比例，最大 440 高）
440 装裱线
460 题名区
520 一眼看懂（三行，行距 40）
660 工艺分解
780 CTA 上沿 → 812 底
```
（内容超过 780 时滚动，CTA 固定）

## 4. 视觉精修（解决「单薄」「不高级」）

### 4.1 搜索框升级

| 项 | 现在 | 改为 |
|---|---|---|
| 底 | 透明 | `rgba(42,38,34,.6)` 半透明面 |
| 描边 | 1px 金 | 1px `rgba(201,162,39,.45)` |
| 高度 | 44 | 44（保持） |
| 图标 | 16px | 18px，金 60% |
| 占位字 | 白 50% | 白 55%，字距 +2% |
| 聚焦态 | 无 | 描边变 1.5px 全金 + 外发光 0 0 0 3px rgba(201,162,39,.12) |

### 4.2 分段控件升级

| 项 | 现在 | 改为 |
|---|---|---|
| 容器 | 1px 金描边透明底 | `--ink-700` 底 + 内阴影 |
| 选中 | 朱红填充 | 朱红填充 + 0 1px 2px 内高光 |
| 未选中 | 金 100% 文字 | 白 60% 文字（选中才用金/白） |
| 分隔 | 无 | 两段之间 1px `rgba(201,162,39,.2)` |
| 切换动画 | 无 | 朱红块 180ms 滑动（用 `::before` 位移） |

### 4.3 卡片升级

| 项 | 现在 | 改为 |
|---|---|---|
| 图片 | `object-fit:cover` 裁切 | **按实比例 contain + 衬底**，器物类用 `cover` |
| 图区底 | `--ink-500` 纯色 | 材质底（玄漆/绢本按类目切换） |
| 角标 | 12px L | 14px L，金 70% |
| 悬浮 | 无 | 按下 scale(.98) + 阴影升档 |
| 类目名 | 20px | 20px（保持），加 `letter-spacing:.01em` |

### 4.4 空状态重做

现在的问题：文字压在卡片上。
改为：**进入空态时隐藏整个列表层**，空态独占内容区（`display:none` 切换，不是叠加）。

空态结构：
```
[图标 32px 金 60%]
「这一格还是空的」  --t-h2
「换个词试试，或者从这三件开始」 --t-cap 白60%
[3 枚 72×72 推荐缩略，间距 12]
```

### 4.5 轴视图重做

现在的问题：内容截断、行距过密。
改为：
- 每段高度自适应，最小 88px
- 竖线贯穿，节点圆 8px 金
- 段标题 20px 宋体 + 段说明 12px 白 60%
- 底部 padding 40px 保证滚到底不贴边

## 5. 详情页精修

### 5.1 图版区

| 项 | 改为 |
|---|---|
| 比例 | 严格按素材实比例（墨龙图 1:1.567；广彩瓶 1:1.33；大神龛 1:1.33） |

| 热点样式 | 40px 圆环 + 中心 6px 朱点 + 外圈 1px 金 30% 光晕 |

### 5.2 一眼看懂

改为 grid 三列（点 6px / 标签 64px / 正文 1fr），行距 40，正文 `--t-body`。

### 5.3 CTA

- 固定底部 88px
- 内容区底部 padding = 88 + 24 = 112
- CTA 上方加 1px 金线（分隔感）
