## 卡片一｜首次参观大学生 · 「先逛再说」型

| 项 | 内容 |
|---|---|
| **代号** | P1-A · 首次参观大学生 |
| **证据来源** | E-01（独立原文）、E-02（摘要） |
| **参观频次** | 第一次来，或十年前来过（E-01 自述「相隔十年」） |
| **同行** | 同学／朋友／同伴，2–3 人（E-02「我们宿舍三个」类表述） |
| **时间预算** | 半天，但实际可用往往只有 **1–3 小时**（E-02 明确「只有 1 个小时走马观花」） |
| **行前状态** | **不清楚馆里有什么、该看什么**；E-01 把「行前要知道看什么」写成自嘲式问题「你的脑子（你要带啥？）」 |
| **核心行为** | 进馆后**按楼层随意走**，没有既定动线（E-01「不按顺序，仅供参考，仅展示部分」） |
| **注意力分布** | 极不均匀：宝石馆看得细、中草药馆「草草看几眼」、夏商周展「没有仔细看」（E-01） |
| **记忆点** | 建筑「宝盒」外形、几件具体物件、拍照体验；**记不住展览的知识结构**（E-01） |
| **对互动的反应** | 对可动手展项印象最深（编钟投影），并注意到「小孩都在点」（E-01） |
| **痛点** | ① 不知道该看什么，怕错过重点；② 时间不够，逛不完；③ 走累了没有休息点 |
| **设计含义** | 需要**「3 分钟看懂一件」**而非「看完整个馆」；需要**固定入口**降低选择成本 |

> **一句话**：他不是不想看，是**不知道先看哪一个**。

## 卡片二｜文博爱好者 · 「带着标准来」型

| 项 | 内容 |
|---|---|
| **代号** | P1-B · 文博爱好者 |
| **证据来源** | E-03（独立原文，北师大历史学院硕士生长评）、E-04（抖音文案，负面） |
| **参观频次** | 多次专程（E-03 自述「两次赴粤」「两次粤博之行」） |
| **知识水平** | 高。能横向比较晋冀陕、鄂豫皖 6 家省级馆的镇馆之宝年代分布（E-03） |
| **行前状态** | **带着明确评判标准**，会先盘点「粤博文物到底什么水平」再看展（E-03 开篇即做此盘点） |
| **核心行为** | 按**展览主题**切换关注点，而非从头到尾看年代牌（E-03 明确的方法论） |
| **他会批评什么** | ① 文物层级不够（「缺乏重磅文物、缺乏独有文物」）；② 重要展品**缺乏视觉引导**（西周青铜盉「很难注意到它」）；③ 部分镇馆之宝**长期未展出** |
| **他会称赞什么** | ① 潮州木雕展**还原潮汕天井民居**；② 端砚展「如实物体验课」；③ 临展「风格独立、特点鲜明」 |
| **痛点** | ① 想看的东西看不到（未展出）；② 展品说明深度不够；③ 现场缺乏「这件为什么重要」的即时解释 |
| **设计含义** | 需要**可核查的事实**与**工艺分解**；需要**明确标注「未展出·数字复现」**而不是含糊其辞；他会检验设计的诚实度 |

> **一句话**：他不缺信息，他缺的是**「这件凭什么值得看」的论证**。

## 卡片三｜亲子家庭 · 「跟着孩子走」型

| 项 | 内容 |
|---|---|
| **代号** | P1-C · 亲子家庭 |
| **证据来源** | E-05（独立原文，大众点评家长笔记）、E-06（转述，弱） |
| **同行结构** | 1 名家长 + 1 名儿童（E-05「带小崽」），有时含祖辈 |
| **时间预算** | **约 2 小时**（E-05 明确「玩 2 个小时差不多」），短于官方建议的 2–3 小时 |
| **决策方式** | **孩子想看什么，就直奔那里**：E-05「崽喜欢看小动物，看鱼，就直奔 3F 海洋馆去了」 |
| **核心行为** | 目标先行、跳过其余展区；对**视觉冲击强**的展项反应最热烈（悬空鲸鲨、恐龙骨架） |
| **对工艺细节的反应** | 钝感。E-05 记的是「螃蟹龙虾标本」「潮州木雕」，但重点是「可参观的地方挺多」，未深入工艺 |
| **真实困惑** | 「小朋友需要身份证吗」「恐龙化石展还有开吗」（E-05 评论区）——**行前确定性信息** |
| **孩子的注意力特征** | 会被**可互动**的装置吸住（E-01 观察到「每次都会有几个小孩在那里点编钟」），但有冷却机制才不会失控 |
| **痛点** | ① 孩子坐不住、注意力短；② 家长不知道该怎么给孩子讲；③ 找不到母婴设施与休息点 |
| **设计含义** | 需要**拟人化、可复述的短句**（家长能当场讲给孩子听）；需要**强反馈**（唤出、粒子）制造惊喜；需要**防失控**（粒子 ≤12、一次性播完） |

> **一句话**：她要的不是知识，是**一个能让孩子「哇」一下、还能讲给同学听的瞬间**。

## 三类用户的共同点（这才是设计的真正靶心）

| 共同点 | 证据 | 对设计的要求 |
|---|---|---|
| **都不知道「先看哪一个」** | E-01 随意走、E-02 只有 1 小时、E-05 直奔 3F、E-03 需自行盘点 | 必须有**固定入口**（镇馆之宝横滑）降低选择成本 |
| **时间都短于预期** | E-01 多处「草草看几眼」、E-02「1 小时」、E-05「2 小时」 | 必须支持**单件 3 分钟读完**，而非全馆导览 |
| **记住的是物件，不是展览** | E-01 记住建筑与具体展品、E-04 记住「白斩鸡」、E-05 记住鲸鲨 | 用**一件文物**做叙事单位，而非用「展览」 |
| **对互动有反应** | E-01 编钟、E-05 海洋馆 | 互动是**注意力锚点**，但必须有**预算上限**防失控 |
| **都需要「确定性」** | E-05 评论区问身份证与展项是否在展 | 状态页要真实（在展/未展出/需预约），**不能含糊** |

## 明确不写进画像的内容（反编造声明）

以下常见画像维度**在本项目中没有任何证据支撑，因此一律不写**：

- ❌ 收入水平、消费能力
- ❌ 职业、专业、年级
- ❌ 性格标签（「热爱文化的」「追求效率的」）
- ❌ 使用手机的品牌、系统偏好
- ❌ 具体的年龄数字（除证据明确提到的「幼儿园中班」「二年级」「6–10 岁学龄儿童」外）
- ❌ 百分比、比例、增长率
