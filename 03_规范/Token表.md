### 5.1 排版规则（5 条）

1. 全项目最多 **3 个字重**（Regular/Medium/Bold），宋体最多 2 个。
2. 中文正文每行**不超过 22 字**，超长分段。
3. 文物名后的年代/材质/尺寸一律用 `--t-num`，三组间以 `·` 和间距分隔，**不叠加竖金线**。
4. 浅底信息文字用 `--ink-700`；辅助数字用 `--gold-800`（silk-200）或 `--gold-700`（silk-100）。
5. **禁止**：负字距、全大写中文、伪粗、多层描边字。

## 7. 对比度检测脚本

> 本表的全部数值由该脚本产出，可复算。存放于 `03_规范/contrast_check.py`。

```python
def srgb_to_lin(c):
    c = c/255.0
    return c/12.92 if c <= 0.04045 else ((c+0.055)/1.055)**2.4

def lum(h):
    h = h.lstrip('#')
    r,g,b = [srgb_to_lin(int(h[i:i+2],16)) for i in (0,2,4)]
    return 0.2126*r + 0.7152*g + 0.0722*b

def ratio(fg, bg):
    l1, l2 = lum(fg), lum(bg)
    if l1 < l2: l1, l2 = l2, l1
    return (l1+0.05)/(l2+0.05)
```

## 8. 禁止项汇总（写进规范页）

| 类别 | 禁止 |
|---|---|
| 色彩 | `--gold-500` 用于浅底正文；`--silk-400` 用作文字色；深底使用青花/石湾绿/端紫；浅底使用通草黄 |
| 透明度 | 白 <45%；金 <75% |
| 字体 | 负字距；全大写中文；伪粗；多层描边；阶梯外字号；超过 3 个字重 |
| 圆角 | 主容器 >2px；除热点外使用 `--r-full` |
| 结构 | 贯穿内容区的竖向分割线（建筑依据：展厅内无立柱） |
| 明度 | 出现四档之外的第五种灰 |
